# Fact-check: `reports/literature-review.md` (LR) and the tables in `reports/state-of-the-art-review.md` (SOTA)

Author: Libor "Burny" Burian. Date: 2026-11-27. Checked by a fact-checking agent against primary sources.

**How it was checked.**
- arXiv papers: `arxiv.org/html/<id>`, `arxiv.org/abs/<id>`, or `ar5iv.labs.arxiv.org/html/<id>` for pre-2023 papers, read with WebFetch. Long pages were read with offsets or targeted string searches.
- Transformer Circuits pages: both are larger than 10 MB, which is over WebFetch's limit, so they were downloaded with curl and searched as text.
- TransformerLens demo: the raw `.ipynb` from `main` was downloaded and its code cells searched.
- Library facts: checked against the installed packages in this project's `.venv` (transformer_lens 4.4.1, sae_lens 6.56.4, trackio 0.45.1).
- Links: every code and page link returned HTTP 200 (curl `-L`).

"Quote" means text copied from the source. Some long sentences are quoted only in part.
